# Collaborative Editor

## 📌 Overview
This project is a real-time collaborative text editor that allows multiple users to edit content simultaneously. It uses WebSocket technology to synchronize text across all connected users instantly.

---

## 🚀 Features
- ✍️ Real-time collaborative editing
- 👥 Multi-user support
- ⚡ Instant text synchronization
- 🔄 No page refresh required
- 🌐 Client-server architecture
- 🎯 Simple and responsive interface

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.io
- MongoDB (for storing documents)

## ⚙️ Installation

1. Clone or download the repository  
2. Open the project folder in terminal  
3. Install dependencies:


npm install


---

## ▶️ Run the Application


node server.js


Then open in browser:


http://localhost:4000


---

## 🧪 Usage

- Open the application in multiple tabs or browsers  
- Start typing in the editor  
- Text updates will appear instantly for all users  
- No refresh required  

---

## 🧪 Testing

- Open 2–3 tabs  
- Type in one tab  
- Verify synchronization in other tabs  
- Check console for errors
